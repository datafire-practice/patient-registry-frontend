# Медицинский реестр пациентов (React + TypeScript)

Приложение для просмотра и редактирования реестра пациентов и их медицинских карт.

## Технологии

- React 19
- React Router
- React-hook-form / Formik
- Material UI
- Vite
- Redux
- TypeScript
- Docker
- Jest
- date-fns

## Запуск

### Локально

```bash
git https://github.com/datafire-practice/frontend.git
cd patient-registry-frontend
npm install
npm run dev
```

### Через Docker

```bash
docker-compose up --build
```
